One line about IT support, with a twist on the classic "turn it off and on again": the user follows the advice far too literally, and the printer still wins. The program deterministically writes exactly one line to `entry.txt`. No network, no randomness, no dependencies.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```
